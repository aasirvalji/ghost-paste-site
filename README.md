# Ghost Paste

Public marketing, support, privacy, and app walkthrough pages for Ghost Paste.

The site uses static HTML and CSS, local image assets, and a recorded app
walkthrough. It has no analytics, cookies, third-party scripts, or build
dependencies.

Published with GitHub Pages from the root of the `main` branch:

- https://aasirvalji.github.io/ghost-paste-site/
- https://aasirvalji.github.io/ghost-paste-site/support/
- https://aasirvalji.github.io/ghost-paste-site/privacy/
- https://aasirvalji.github.io/ghost-paste-site/review/
